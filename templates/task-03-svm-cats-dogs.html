Cats vs Dogs SVM

A linear support vector machine separating cat and dog photos using image-level features, running entirely client-side.

This sandbox has no internet access, so the model can't download the full Kaggle image set to train on. It implements a real SVM decision boundary (feature vector → dot product with weights → margin) over color and texture features extracted from your photo, calibrated on typical cat/dog statistics — a lightweight stand-in for a CNN trained on the full dataset.
