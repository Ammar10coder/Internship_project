Hand Gesture Recognition

Classifies an uploaded hand photo into Palm, Fist, Thumbs Up, or Peace using shape and skin-region features extracted in your browser.

This sandbox has no internet access, so it can't download the full LeapGestRecog dataset to train a CNN on. This page implements the real feature pipeline — skin-tone segmentation, bounding-box shape, and silhouette-width analysis — feeding a rule-based classifier calibrated on typical gesture proportions, as a lightweight stand-in for the trained model.
Input

Upload a hand photo

Works best against a plain background, one hand, good lighting.
