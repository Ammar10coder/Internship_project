# Prodigy InfoTech Machine Learning Internship

This repository contains the Machine Learning internship tasks completed as part of the **Prodigy InfoTech ML Internship Program**.

## 📌 Tasks Completed

### Task 1 – House Price Prediction
- Linear Regression
- Predict house prices based on:
  - Square Feet
  - Bedrooms
  - Bathrooms

### Task 2 – Customer Segmentation
- K-Means Clustering
- Segment customers based on:
  - Annual Income
  - Spending Score

### Task 3 – Cats vs Dogs Classification
- Support Vector Machine (SVM)
- Image classification using OpenCV and HOG features

### Task 4 – Hand Gesture Recognition
- CNN-based Hand Gesture Recognition
- Image classification using TensorFlow/Keras

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Prodigy-InfoTech-ML-Internship.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open in your browser:

```
http://127.0.0.1:5000
```
